**Información de la carpeta:**
La carpeta **docs** se enfoca en recopilar la **documentación** realizada para el proyecto, como la estructura de descomposición de tareas, requerimientos funcionales y no funcionales, tablas de riesgo, propuestas de mejora, entre otros. 
Este espacio también alberga los **diagramas UML** que definen el sistema, **gráficos**, **estadísticas**, **arquitectura** y detalles.
